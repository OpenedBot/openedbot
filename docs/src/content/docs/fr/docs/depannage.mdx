## Mon bot ne répond pas

1. Vérifiez que vous êtes dans le bon espace et que vous avez ouvert le bon bot.
2. Ouvrez **Réglages > Edge** et vérifiez l’état de votre machine.
3. Vérifiez que le fournisseur d’IA du bot est toujours disponible : **Réglages > Modèles**, ou **Gérer le bot… > Modèle** pour ce bot.
4. Si le bot est en train de répondre, attendez ou arrêtez sa réponse avant d’envoyer un nouveau message.

Si la machine n’est pas prête, suivez le guide pour [relier votre machine](/fr/docs/machine). Si le problème concerne un fournisseur ou un modèle, consultez [les réglages](/fr/docs/reglages#fournisseur-dia-et-modèle).

## La conversation affiche « À vérifier »

Une réponse a été coupée avant que openedbot sache si elle avait abouti (par exemple quand la machine ou le service redémarre pendant le travail du bot). Pour ne pas refaire deux fois la même action, le bot n’en commence pas d’autre dans cette conversation. Cliquez sur **À vérifier**, en haut de la conversation, puis :

- **Réconcilier** : openedbot redemande à votre machine ce qui s’est vraiment passé. C’est le bon premier choix.
- **Abandonner** : vous renoncez à cette réponse.
- **Relancer avec risque** : le bot recommence, au risque de refaire une action déjà faite.

## Je ne trouve pas ma machine

Vérifiez que vous avez ouvert le bon espace, puis ouvrez **Réglages > Edge**. Si aucune machine n’y apparaît, reprenez les étapes de la page [Relier une machine](/fr/docs/machine).

## Mon ticket a expiré

Un ticket ne fonctionne qu’une fois et expire après cinq minutes. Quand la console affiche « Ticket expiré », fermez la fenêtre, choisissez de nouveau **Appairer depuis le serveur**, relancez la commande `edge-setup link` sur la machine et collez le nouveau ticket à l’invite masquée. Ne le collez jamais dans une commande et ne le partagez pas.

## Je ne peux pas ouvrir mon compte

Connectez-vous avec la même méthode que lors de votre inscription, Google ou adresse e-mail. Si vous avez oublié votre mot de passe, utilisez le lien **Mot de passe oublié ?** sur la page de connexion.

## L’installation de ma machine est bloquée

Reprenez les commandes affichées dans la console, une à la fois et dans l’ordre. Les symptômes les plus courants et le geste à faire sont dans [edge-setup](/fr/docs/edge-setup#dépannage-court). Si le message affiché reste difficile à comprendre, [écrivez au support](/fr/docs/support).

Voir aussi les [questions fréquentes](/fr/docs/faq).

## Besoin d’aide supplémentaire

[Écrivez au support](/fr/docs/support). Indiquez ce que vous vouliez faire, ce que vous avez vu, le texte du message d’erreur s’il y en a un, et depuis quand le problème se produit.

N’envoyez pas votre mot de passe, vos clés de fournisseur ou un ticket.
