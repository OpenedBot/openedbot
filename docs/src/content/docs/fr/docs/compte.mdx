Ouvrez [openedbot.app](https://openedbot.app).

## Créer votre compte

Vous pouvez vous inscrire avec Google ou avec votre adresse e-mail. Avec une adresse e-mail, saisissez le code à six chiffres reçu dans votre messagerie : aucun mot de passe n’est demandé. Le même formulaire sert à créer votre compte et à vous reconnecter.

Le code vaut dix minutes et autorise cinq essais. Si le message tarde, vérifiez les courriers indésirables. Après une minute, vous pouvez demander un nouveau code ; utilisez alors le plus récent. Si le code a expiré ou que les cinq essais sont épuisés, demandez-en un autre.

Vous pouvez relier votre compte Google plus tard dans **Réglages > Mon compte**, section **Connexion**.

## Suivre le parcours de bienvenue

Après votre inscription, la console vous guide en deux étapes :

1. **Espace de travail** : le nom de votre organisation, l’endroit où vivront vos bots et vos conversations, puis votre **Nom d’utilisateur**, celui que vos bots emploieront pour s’adresser à vous (2 à 32 caractères : lettres, chiffres et tirets).
2. **Configuration** : la machine de vos bots, le **Fournisseur d’IA** et le **Modèle**. Un court essai vérifie le modèle en arrière-plan, et vous arrivez tout de suite dans l’application. Le détail pour la machine est dans [Relier une machine](/fr/docs/machine).

Vous pouvez passer l’étape **Configuration** avec **Configurer plus tard**, puis relier la machine plus tard depuis **Réglages > Edge**.

Le parcours ne crée pas de bot : vous créez le premier ensuite dans l’application, avec **Nouveau bot**. Voir [Créer un bot](/fr/docs/bot).
