openedbot vous permet de créer des bots d’intelligence artificielle adaptés à vos tâches. Vous les préparez et vous leur parlez dans la console. Le travail des bots s’exécute sur **votre** machine, pas dans le cloud openedbot. Quand cette machine est reliée, vos bots peuvent vous répondre.

Vos bots tournent sur [Hermes](https://github.com/NousResearch/hermes-agent), l’agent de référence que `edge-setup` installe. D’autres agents ou passerelles peuvent aussi se connecter à openedbot grâce à son protocole de connexion public et versionné.

## Votre parcours

1. [Créez un compte et votre espace](/fr/docs/compte).
2. [Reliez une machine](/fr/docs/machine).
3. [Créez votre premier bot](/fr/docs/bot) avec **Nouveau bot**.
4. [Lancez une conversation](/fr/docs/conversation).

Vous pouvez commencer à configurer un bot avant de relier une machine. Il répondra une fois la machine prête.
