Le support est assuré par une personne de l’équipe openedbot. Votre message n’est pas envoyé à un bot.

## Depuis la console

Dans l’application, choisissez **Contacter le support** en haut de l’écran : il ouvre la page Support. Vous pouvez y **Joindre une capture** et utiliser des listes, des liens ou du code.

Hors de l’application, par exemple sur la page de connexion ou pendant le parcours de bienvenue, une bulle d’aide en bas de l’écran ouvre le support. Si vous n’êtes pas encore connecté, elle vous demande une adresse e-mail pour que l’équipe puisse vous répondre.

## Pour nous aider à comprendre

Décrivez :

- ce que vous vouliez faire ;
- ce que vous avez vu, en copiant le texte du message d’erreur si possible ;
- si le problème concerne votre compte, votre machine ou un bot ;
- depuis quand cela se produit.

## Suivre la conversation

La conversation reste sur la page Support, avec la réponse de l’équipe. Vous pouvez la reprendre plus tard, y compris depuis un autre appareil avec le même compte ; **Mes conversations** liste vos échanges. Quand l’équipe a fermé une conversation, écrivez-y pour la reprendre, ou ouvrez une **Nouvelle conversation**.

N’envoyez pas votre mot de passe, vos clés de fournisseur ou un ticket.
