Choisissez un bot dans la console pour ouvrir sa conversation. Vous pouvez y poser une question, donner une consigne ou poursuivre un échange précédent.

## Envoyer un message

Écrivez dans le champ en bas de la conversation.

- Sur un ordinateur, **Entrée** envoie le message et **Maj + Entrée** ajoute une nouvelle ligne.
- Sur un téléphone, **Entrée** ajoute une nouvelle ligne et le bouton **Envoyer** transmet votre message. Le clavier se ferme après l’envoi.

## Lire les réponses

Le bot peut répondre avec du texte, des liens, des listes ou du code.

Si le bot est occupé, attendez la fin de sa réponse ou arrêtez-la avec le bouton **Arrêter la génération**. Sur un ordinateur, dans la conversation d’un seul bot, **Échap** l’arrête aussi quand le champ de message est vide.

Si une action demande votre accord, lisez la demande, puis choisissez **Autoriser une fois** ou **Refuser**. Vous retrouvez vos décisions dans **Réglages > Décisions**. Voir [Actions à approuver](/fr/docs/reglages#actions-à-approuver).

## Parler à plusieurs bots dans un groupe

Un groupe est une conversation partagée avec plusieurs bots.

1. Choisissez **Nouveau groupe**.
2. Donnez-lui un nom et choisissez ses **Membres** : 2 à 6 bots.
3. Si vous le souhaitez, choisissez les **Répondants par défaut** et le **Mode de réponse** : **Chacun répond**, ou **Réponse d'équipe**, où les membres contribuent puis une seule réponse finale est écrite.

Pour vous adresser à un bot précis, mentionnez-le avec @ suivi de son nom. Une @mention explicite prime toujours sur les répondants par défaut.

## Masquer une conversation

Masquer retire la conversation de votre liste habituelle. Elle n’est ni archivée ni supprimée. Vous la retrouvez dans **Réglages > Archives**.

Le bot ne répond pas ? Voir [Résoudre un problème](/fr/docs/depannage).
