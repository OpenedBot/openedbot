Un bot est un assistant que vous réglez pour vous aider dans une tâche. Chaque bot a son propre nom, sa persona et son modèle.

## Créer un bot

1. Dans la console, choisissez **Nouveau bot**.
2. Partez d’un modèle prêt à l’emploi, ou d’une page blanche.
3. Donnez-lui un nom, puis créez-le. Un nom suffit : tout le reste se règle ensuite dans **Gérer le bot…**, depuis le menu du bot.

Le bot se prépare ensuite sur votre machine. La conversation montre les vraies étapes au fur et à mesure : son espace, ses règles, puis ses outils, nommés un par un. Quand il est prêt, le champ de message apparaît et le bot vous accueille. Pendant la préparation, **Supprimer** reste grisé : attendez qu’il soit prêt.

Vous pouvez réutiliser le nom d’un bot supprimé : le nouveau bot reçoit un identifiant libre, sans toucher à l’ancien.

Le modèle d’IA du bot se choisit dans **Gérer le bot… > Modèle**. Sans modèle propre, il suit celui de votre machine, réglé dans **Réglages > Modèles**. Le fournisseur d’IA peut facturer les réponses selon votre compte chez lui.

Vous pouvez créer un bot avant de relier une machine. Il attendra que la machine soit reliée pour travailler.

Pour partir d’un bot existant, choisissez **Dupliquer…** dans son menu. La persona, le visage, le modèle et les préférences suivent ; ses règles d’approbation repartent à « demander avant d’agir ».

## Importer des bots existants

Si votre machine porte déjà des bots, ouvrez **Réglages > Importer des agents** et choisissez ceux qui vous servent. Les routines importées restent en pause jusqu’à ce que vous les activiez.

## Personnaliser votre bot

Dans **Gérer le bot…** :

- **Persona** : qui est le bot, sa mission et sa façon de vous aider. Donnez-lui des consignes précises et faciles à suivre.
- **Skills et outils** : ce que le bot peut utiliser.
- **Connecteurs MCP** : les services externes auxquels il peut se brancher.

Les autres réglages (mémoire, routines, approbations) sont décrits dans [Régler vos bots et votre compte](/fr/docs/reglages).

## Archiver ou supprimer un bot

Archiver retire le bot de la liste habituelle, sans effacer ses conversations. Vous le retrouvez dans **Réglages > Archives** et pouvez le restaurer.

Supprimer un bot l’envoie à la corbeille. Ses sessions et son profil sont effacés sur votre machine, mais vous pouvez encore le restaurer depuis **Réglages > Archives** : il revient dans la liste avec un profil vide. La console vous demande de confirmer avant de le supprimer.

Pour l’effacer pour de bon, ouvrez **Réglages > Archives**, section **Corbeille**, et choisissez **Supprimer définitivement**. Le bot, ses conversations et leur historique sont alors effacés, aussi sur votre machine. Cette suppression ne peut pas être annulée.
